# MS-RLSurv V8 RL and Medical Imaging Code

This directory contains the reusable source code and experiment launch/audit scripts from the MS-RLSurv evidence-interface and reinforcement-learning work.

Included: `src/MSRLSelect` Python modules and selected V7/V8/R3 experiment scripts.
Excluded intentionally: patient data, patch/UNI tensors, outputs, caches, checkpoints/weights, predictions containing patient-level records, and secrets.

The scripts are research records and require the original environment and data manifests. Test-set data are not included.
