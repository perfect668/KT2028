# W149：有限数据下的过拟合与验证稳定性

日期：2026-11-12。用户授权沿PANTHER固定表征、小预测头、正则/压缩/粗细尺度受控对照继续，并明确优先解决数据与小验证集问题。

## 两个问题、两种处理

模型过拟合是训练得到的规律难以泛化；小验证集使性能估计和选模波动大。扩大内部验证能降低估计波动，但会减少每次训练人数；重采样能够更充分使用已有患者，不能创造新的独立患者/事件。原CRC开发439人83事件中，原内验44人8事件；LUAD开发363人123事件中，原内验36人12事件。这种小子集不能承担反复筛选几十种模型的任务。

方法依据：[Riley等BMJ2020样本量与重采样](https://www.bmj.com/content/368/bmj.m441)、[作者对单次切分与交叉验证的澄清](https://www.bmj.com/content/368/bmj.m441/rr-0)、[Cawley与Talbot关于选模方差/偏倚](https://jmlr.org/papers/v11/cawley10a.html)。这些支持在开发集内采用重采样并限制搜索，同时保留独立评价；不能解读成将已有外层留出标签加入训练并继续称独立测试。事件数/参数的固定经验阈值也不能直接套到深度网络作为充分证明。

## 数据层面的处理原则

患者级隔离全部切片/patch；保留真实删失病例和随访，不用删失者充当“存活满五年”负例。重复抽patch/增广增加同一患者输入变化，不增加患者/事件。先审计实际事件、随访、重复关系与队列来源，结合训练容量做正则；不通过删除难例、挑分折或更换OS/DSS来抬分。最终可提高数据支持的办法仍是更多可靠独立患者/事件、补充合法随访或独立队列，但本轮不扩大下载或原片存储。
