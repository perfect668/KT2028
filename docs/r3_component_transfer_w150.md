# W150：五个官方仓库与 R3 的组件移植审查

日期：2026-11-12。交付是源码审查与候选设计；没有实现新的预测器、启动训练、读取患者特征或新增验证/外层预测。候选尚未替换现行方案。服务器只运行了 CPU 合成张量的模块检查。

## 结论

值得借鉴的是信息组织方式，不是把五套模型串起来。优先考虑两项彼此独立的改动：**EAGLE 的空间上下文模块替换 R3 粗尺度编码器**；**nnMIL 的随机特征子集注意力替换 R3 细尺度汇聚器**。前者提供局部空间约束并减参，后者不增加参数，检验注意力是否过度依赖少数特征。两者都只是待验证假设。

DSCA 的粗引导细跨注意力已在 R3 中；剩余可借鉴的是在区域配对之后再统一汇聚。PANTHER 更适合提供覆盖不同形态的选区先验；OTSurv 的软原型汇聚可作后续备选。暂不把分类辅助损失、Cox 目标和新模块一起移植。

## 2. R3 已有什么，参数主要在哪里

实际入口是 [survival_network.py](../kt2028/survival_network.py)。每张切片分别编码，患者级汇聚始终保留全部粗区域，只处理已经观察的真实细特征。

```mermaid
flowchart LR
    C[全部粗尺度特征] --> CE[粗尺度 Transformer]
    CE --> Q[用对应粗区域查询细图块]
    F[已观察的细尺度特征] --> Q
    Q --> FE[细区域 Transformer]
    CE --> G[粗细门控]
    FE --> G
    G --> P[分别汇聚粗细证据]
    P --> H[融合与五年度生存头]
```

CPU 实例计数：

| 部分 | 参数数 |
| --- | ---: |
| 全部 R3 | 2,340,615 |
| 粗尺度 Transformer | 527,104 |
| 细区域 Transformer | 527,104 |
| 粗查询细的局部跨注意力 | 263,168 |
| 两路输入投影合计 | 524,800 |
| 两路注意力汇聚合计 | 131,842 |
| 患者融合层 | 132,608 |
| 最后五年度输出层 | 1,285 |

最后一层已经很小。只缩小最后一层不会显著减少整体容量；简单减参也不是过拟合的充分解法，W136 的 128 维 R3 和 W149 小头结果已经提供了反例。

## 3. EAGLE：优先检验空间编码，而不是照搬整套分类监督

**源码事实。** MASE 将输入组成 `[1,1,H,W,D]`，采用 1/3/5/7 核的四个 Conv3d 分支，每支 8 通道，拼接后 32→1，再加残差。共 **4,033 参数**。这是空间邻域与嵌入维的联合卷积；并非四种真实图像倍率。声明的 MaxPool3d 没有在 MASE.forward 中调用。

整网还用同一个线性分类器计算区域类别分数与患者类别分数，注意力由各类别 exp 分数之和归一化。训练增加高注意力邻域的切片类别监督和背景注意力惩罚；这是官方 LUAD/LUSC 分类入口的语义。

**拟移植位置。** 只替换 `coarse_encoder`：粗特征投影与位置编码 → 按每张切片真实坐标放回网格 → MASE → 取回有效粗区域。其余粗查询细、细区域编码、门控、汇聚和生存头保留。

若适配器仅包含无参数的坐标放置/取回和 mask，总参数为 **1,817,544，减少 523,071，约 22.3%**。若在原 Transformer 前再叠 MASE，则只会增加 4,033，不能称为减参。若未来增加额外归一化等层，参数需重新实算。

**为什么值得试。** R3 当前允许任意粗区域相互作用；局部卷积先强调真实邻近区域的结构，可能减少小样本下学习任意远距离关联的自由度。粗路径全部可见，也避免在稀疏细尺度网格上把未观察信息当背景。

**边界与代价。** 替换也会移除粗路径的显式全局 token 交互，可能损失远距离组织关系，不能预设只会获益。Conv3d 还把特征维的相邻位置当作可卷积邻域，这种假设需要实测。参数少不等于显存低：H×W×D 画布和 32 通道中间激活可能很大。应采用已有精确分块思路，并核验训练 dropout 与梯度一致；不按区域序号随意拼方阵，也不让不同切片在画布上相邻。孔洞保留坐标与有效 mask，不将缺特征位置当真实病理背景。

当前粗区域步长为 448µm，不能把同核大小下的感受野称为此前 EAGLE 细尺度打包的相同物理视野。如果改成仅空间二维的多邻域算子，则应另称 EAGLE 启发的变体，不冒称官方 MASE 等价实现；暂不同时开展两套版本。

**不随模块一起搬入的内容。** 年度 hazard 不是互斥类别，不能直接沿用类别 logsumexp 打分和局部交叉熵；未提取位置也不是真背景标签。先只考察空间模块，保留现有年度删失 NLL。CRC 整网 EAGLE 首折 C=0.672 对 R3=0.596 是既有结果，不能定位为 MASE 的因果收益，也不能把这个已查看的外层折再次当作新模块选型集。

## 4. nnMIL：把注意力学得更稳，不丢掉被汇聚的完整特征

**源码事实。** 训练时随机选特征维子集，仅用于注意力首层打分；被注意力加权的值向量仍是完整 D 维。评价用固定随机排列的重叠子集覆盖，原生 Cox 分支对风险输出做 logmeanexp。

**拟移植位置。** 只修改 `fine_pool`，保留 R3 现有两层门控注意力权重形状：256 维输入中抽 128 维计算打分，仍加权全部 256 维细区域值。是随机限制“凭什么判断哪个区域重要”，而非把一半细特征扔掉。新增参数 **0**。

训练每次一个子集；评价固定 seed=42、keep=128、stride=32，可得到 5 个覆盖子集。复用上游的细编码和门控，只重复汇聚/读出，无须把两个 Transformer 重跑 5 遍。必须同步说明细辅助分支如何使用同一汇聚规则。

**生存适配。** 不直接搬 Cox 的风险 logmeanexp 到年度 hazard。候选可平均五份完整生存曲线；平均后的曲线仍单调，按相邻生存比值还原年度 hazard 后计算同一 NLL。这是明确的生存输出适配，不是官方 nnMIL 原封不动的评价入口。零细观察仍走原粗路径。

**作用假设与现有证据。** 希望减少注意力紧盯少数偶然相关维度，但上游仍可能记忆训练患者，随机子集不是保证。W147 的独立 nnMIL 在本队列并未显示强收益，故这里只值得做低成本单组件检验。W136 的注意力输出小门控和此处的打分子集随机化不同，不能重复命名旧实验。

## 5. DSCA：粗引导细已经有了，可考察“先配对，再汇聚”

**源码事实。** CAPool 用粗区域查询对应细图块；`WSIHierNet` 在 `join='post'` 时分别编码两路，再按同一粗区域位置拼接/相加，之后全局汇聚。R3 的 `local_attention` 已经继承第一项；目前 R3 后半部分是两路各自汇聚，再患者级融合。

**剩余可移植点。** 用同一区域的粗细配对证据共同生成区域权重，再汇总患者表示。对全部粗区域保留支持；细表示只来自已观察父区域。若共用一组分数，粗路在全粗集合归一化，细路在已观察集合重新归一化，避免细证据幅度仅因观察比例变小；观察状态 q 继续输入。零细时明确退回粗模式。

这是 DSCA 启发的部分观察融合设计，官方完整配对输入不能直接替代本项目缺失细区域接口。区域级联合融合可能增强粗细对应关系，但不证明能增加预后信号。现有 DSCA 整网只在 LUAD 首折排序改善，优先级低于前两项；不额外堆一个同功能跨注意力层。

## 6. PANTHER：更适合形态覆盖先验，不建议再拼接高维统计

**源码事实。** 冻结原型的设置下，以训练图块建立原型，再为每张切片计算混合权重、均值、协方差统计。16 原型×1024 维 allcat 表征为 32,784 维。仓库同时提供线性头和按原型组织、可共享部分权重的 `IndivMLPEmb`；W147/W149 实测的是小线性头，不能宣称已穷尽其全部读出结构。

**适合 R3 的借鉴。** 先在各内折 Train 的原始粗尺度 UNI 特征上拟合形态原型，再按形态组分配细区域获取预算，与相同预算的随机选区比较。让被选区域覆盖不同形态，减少只反复看相似区域的可能性。此过程可先固定，无需新增强化学习网络。

原型拟合只用 Train；推理选区只看当时可见粗特征。不能利用未观察细特征选自己，也不能将 20× 原型直接当成 5× 原型。原型只表示统计形态组，不能命名为已核实的肿瘤/间质标签。同父区域预算下还应报告实际细图块数，并非天然等成本。

该建议针对信息覆盖，不是已证实的抗过拟合方法。暂不把 32,784 维统计直接拼入 R3；W149 的强正则、压缩和粗细统计拼接已没有显示稳定排序收益。PANTHER 继续作为固定表征参考更有价值。

如果限定在预测器内部，也可借鉴“按原型分组、共享小映射”的结构：用上述固定粗形态归属，把已经观察的细区域表示分组汇聚，再经共享小映射与组间汇聚输出 256 维细表示。空组必须 mask，零细仍回粗路径，不拼接数万维统计。这是新的 PANTHER 启发式区域汇聚候选，既不是原生 GMM 统计也不是已跑过的小头；优先级低于前两项，不能从固定原型直接推断泛化会变好。

## 7. OTSurv：汇成少量“代表信息”，有接口位置但不是首选

**源码事实。** 1024→256 投影后，把图块软分配到 16 个可学习原型，使用可微传输求解，再用 16→1 的线性层汇聚。`ot_attn.py` 对每个向量减去其最小值、归一化距离，质量约束 rho 在前 10 轮逐渐放宽到 1。rho 是传输质量，不是实际已获取细图块比例。

**最小移植。** 在 `gated_fine` 后替换 `fine_pool`：N 个 256 维区域 → 16 个 256 维代表 → 256 维患者细表示，保留原 R3 投影/融合/年度头。16×256 的原型和 16→1 读出共 4,113 参数，替代原 65,921 参数汇聚器，净减 61,808（全网约 2.6%）。没有删除 `fine_encoder`，因此不能称消除了其 N² 注意力成本。

若把压缩放在 `fine_encoder` 前，必须把槽位上下文恢复到原区域，因为后续粗细门控逐区域使用 hf。这需要新的压缩—恢复设计，已不是直接换一个官方模块，暂缓。局部父区域本来就只有约 16 个细图块，在每个局部袋内再设 16 个原型也没有明显压缩意义。

迭代求解不是简单线性池化，需核查求解收敛、全梯度、退化相同特征的距离除零、真实峰值显存和用时。不得无声 detach/截断图块或将 `num_iters=3` 当成整个求解只有三步（还配置了最多 1000 次迭代）。W147 独立 OTSurv 在 CRC 的内部 C≈0.518，尚无优先叠加的实证依据。

## 8. 后续最小受控验证建议（未启动）

仅先比较三个条件：原 R3；仅换粗编码器的 MASE-R3；仅换细汇聚器的 nnMIL-R3。两项移植先分别对照，单项未显示收益前不组合，也不附加新损失、选区或 Cox 目标。

如后续实施，应使用相同患者开发池、相同内折 Train/验证清单、OS/行政删失、冻结 UNI、物理尺度、观察预算、优化与选模规则，重新训练匹配的 R3 对照。W149 的 24 个小头及 W147 的旧小内验数字均不能充当这些新组件的匹配基线。建议沿开发池三个事件分层内折，先锁定训练/预算/选模规则再运行；不增加新外层预测，不按结果追加网格。已多次查看的旧外层结果只能提供背景，不能作为独立确认性验证。

软件验收先于真实实验：坐标顺序置换后输出一致；切片隔离、孔洞与未观察细信息隔离；零/部分/完整观察；前向/梯度/重载；实际最大 Train 输入的内存。MASE 分块如启用，需核原模块训练 dropout 和梯度等价；nnMIL 子集覆盖及生存曲线单调性需核验。

展示应包括三内折逐折 C-index 与均值（排序能力），IBS/年度 NLL（概率误差），训练—验证曲线、各观察预算的收益，以及实际时间/峰值显存。空间/注意力图只解释模型关注，不当病理因果证明。若增加细信息后性能不稳定，优先做配对的细内容控制，区分真实细信息与观察量/区域分布效应；不能靠一张好看的注意力图认定机制有效。
