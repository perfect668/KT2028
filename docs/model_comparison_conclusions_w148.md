## 五项结论

1. **参数量不足以单独解释。** PANTHER仅3.3万可训练参数，在CRC仍为Train0.909/内验0.537，在LUAD为0.934/0.703。监督自由度还取决于输入统计的维数、正则强度、训练方式和结局事件支持。3.3万维线性读出相对数百患者仍可灵活拟合；结果不支持单纯继续缩宽度即可解决问题，也不支持容量完全无关。
2. **存在可用信号，稳定泛化仍未建立。** LUAD上PANTHER/OTSurv优于nnMIL，CRC三者均低；EAGLE CRC外层较R3/DSCA改善而LUAD无改善。不能因CRC一份内部折低就断言图像无信息，亦不能由一个高分宣布方法适合整个任务。
3. **需要同时看排序和概率。** OTSurv LUAD内验C0.653，但IBS0.152234与常风险参考0.152051接近；PANTHER LUAD在C和IBS上均有改善线索。EAGLE CRC C/IBS改善、NLL较R3变差。不同输出/损失、删失时点支持与校准需要分开分析，不能只挑一个有利指标。
4. **受约束的信息聚合值得继续研究，复杂选择器尚无实证收益。** PANTHER固定无监督形态统计、OTSurv可微软选择在LUAD有线索，CRC仍难；此前W136固定/交替选区均未超过初始配对。当前没有证据支持立即把更多复杂度放到RL/交替训练。原型、目标、批次和优化配方同时变化，本轮比较不能将全部收益因果归给某一个模块。
5. **验证稳定性是下一阶段的核心。** 小内验集既用于选模又用于观察方法，会有选择乐观性和高方差。EAGLE的内外层反差表明，即便内部C接近0.8也不能直接外推。正式比较必须在协议冻结后完成预定留出评价；已有外层若被用于后续设计选择，其开发暴露应披露，不能事后称为全新独立测试。不同论文的OS/DSS、图块视野、机构分折与本项目不同，不能拿论文榜单数值作直接达标线。
