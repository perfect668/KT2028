## 4. 机制与过拟合

第三项gate+fine KV LN已完成4轮/148步，选第4轮。完整观察C/NLL/IBS为0.623717/0.617669/0.146685，对实际对照gate三项均未改善，因此不纳入。20%为0.621057/0.616201/0.146786，零细为0.625618/0.596423/0.145895；不按某个单独预算的IBS重新选择。best SHA为`cbe5e5ffa595733347deba6ca3eea330b420c35c7fb367f33d1d77eda8d7e3e2`。

同8例Train、同种子观察区域的机制统计：完整观察时粗患者表示相对未门控向量的范数中位数，由原R3的0.525变为1.025；20%时约1.005。观察越多导致粗路整体减半的问题得到结构与实测核对。
