## 1. 核心判断

当前最值得处理的是**细上下文残差公共分量过强、局部粗引导的实际增量较弱，以及粗门控随观察量改变表示幅度**。没有发现父子配对、padding、拼接维度或年度NLL计算错误。

需要修正只看W157统计可能产生的理解：细区域差异占比约5%，不等于95%的有用信息被删除。逐层重构显示，主要是自注意力加入了较大的、区域间相似的公共分量，原区域之间的绝对差异仍保留。仅在出口加LN，也不自动消除这个公共向量。

另一个明确的数据利用限制：本划分292名Train中29名在首年内删失，当前年度离散NLL对这些病例的图像损失和梯度都为0。改变这一点涉及时间建模协议，应与架构细节分开处理。

## 4. 局部跨注意力：粗引导在best中实际较弱

冻结其他参数和真实fine输入，比较原版与局部等权。等权输出独立重构为`W_out(mean(W_V * fine_embedding + b_V)) + b_out`，仍含原值投影和局部位置；不是直接平均1024维后跳过整个细流。

| 诊断量 | best第4轮 | last第12轮 |
| --- | ---: | ---: |
| 局部注意力输出与等权输出相对RMS差 | 3.67% | 4.58% |
| 局部改等权，五年度生存率均值的绝对变化 | 0.000158 | 0.009897 |
| 局部粗query置零，同一输出变化 | 0.000157 | 0.009745 |
| 去掉细上下文入口显式加的父区域全局位置，同一输出变化 | 0.039386 | 0.063262 |

这里0.000158相当于0.0158个百分点，既不是C-index增量，也不是死亡概率改善。所有替换均为冻结权重Train诊断；去位置/置零可能偏离训练分布，不能据幅度大小判定该信息“有害”或谁的临床贡献更大。粗query置零仍保留MHA的投影bias，且其他粗通路不动。

W157的细内容置零能改变输出，说明内容确实被利用；本轮补充定位为**best主要像均值细内容汇聚，粗引导细块差异的增量较弱**。不能再把“用了跨注意力”本身作为有效区域交互的证据。

[DSCA固定官方CAPool源码](https://github.com/liupei101/DSCA/blob/a749074cb3415c3a6eb83bee39191bdb69968dcc/model/model_utils.py#L268)的fine链是卷积→LN→ReLU→跨注意力；粗query的Conv1d明确`norm=False, activation=False`。R3的Linear→GELU加位置后直接进MHA，与这条完整链不同。下一步若检验入口校准，应明确改Q还是KV，不能称照搬“两路都LN”。本轮未改代码。

## 5. 细上下文：定位到公共分量增大，而非区域信息全部抹除

对同一患者的区域矩阵X，定义`E_diff=mean((X-mean_region(X))²)/mean(X²)`。它是差异能量占比，不是保留信息量、有效秩或预测效能。

| 同一粒度的阶段（best） | 总RMS | 区域间差异RMS | 差异能量占比 |
| --- | ---: | ---: | ---: |
| 局部细汇聚输出 | 0.1563 | 0.09775 | 40.32% |
| 加父区域全局位置 | 0.2198 | 0.11232 | 26.24% |
| 加自注意力残差 | 0.4607 | 0.11280 | 5.97% |
| 加FFN残差 | 0.5462 | 0.12177 | 4.98% |

自注意力新加分量自身RMS约0.3892，区域间差异RMS只有0.00858，差异能量占比约0.0488%。它主要是该患者内各区域相近的公共向量。与此同时，输入区域差异RMS0.11232变成0.11280，绝对差异并未消失；是公共部分变大、主导总幅度。中位数逐列独立计算，不能由两列中位数直接重算第三列。

初始化也有同样趋势：加位置后22.76%→自注意力残差后6.45%，说明这种行为至少部分来自结构/初始化，不全是训练后记住病例。last并未进一步单调降为零，不能据此断言“越训越坍缩”。

这给出的具体候选是**校准残差新加分量相对主通路的幅度**。[LayerScale原文](https://openaccess.thecvf.com/content/ICCV2021/html/Touvron_Going_Deeper_With_Image_Transformers_ICCV_2021_paper.html)及[官方实现](https://github.com/facebookresearch/deit/blob/main/cait_models.py#L129)在Pre-LN注意力/FFN输出乘小初值的可学习通道尺度，再与主路相加；[ReZero原文](https://proceedings.mlr.press/v161/bachlechner21a.html)用零初始化残差门控。它们支持幅度控制这一设计原则，论文深层模型收益不能当作单层R3的收益保证，也不据此增加网络深度。

[纯注意力秩退化论文](https://proceedings.mlr.press/v139/dong21a.html)针对无skip/MLP的条件；R3有残差和FFN，不能直接套用其rank-1定理。这里观察到的是患者内公共分量占优。

## 6. 归一化：应该检查位置，不能只加层数

现有Pre-LN把子层输入校准后，子层输出仍会直接叠加到幅度较小的主路；编码器外部没有最终norm。这与[Xiong等原文](https://proceedings.mlr.press/v119/xiong20b.html)讨论的归一化位置相关，但归一化本身不保证输出区域具有区分性。

同best8例冻结诊断：

| 表示干预 | 最终细区域差异能量占比 |
| --- | ---: |
| 原版 | 4.984% |
| 只对原hf施加无仿射出口LayerNorm | 4.920% |
| 自注意力残差新加分量乘0.1，再重新计算原FFN | 22.857% |
| 该自注意力新加分量置零，再重新计算原FFN | 24.771% |

该表只定位表示变化，不产生验证指标、不说明移除注意力更好，也不能否定新增LN经过训练后可能产生的收益。逐区域LN对每个向量的通道统计归一化，不等同减去患者内区域平均向量；两者不能混为一谈。不自动对区域均值做中心化，因为患者级平均形态本身可能含预后信息。

拼接前粗细RMS比已接近1，逐分支归一化的优先级低于这次定位到的残差比例。缺失分支应保持零语义，新增带beta的LN需要可见性mask或其他保零方式；不直接采用患者batch1的BN。

[EAGLE固定实现](https://github.com/WuLabMDA/EAGLE-Net/blob/6e8b1147c1732812d3f4e0f59526ff54452a228b/Eagle_net_model.py#L114)在MASE之后、打分之前有norm_C；此前W151的MASE-only替换未移植这层LN，因此不能用其旧结果宣称已排除该位置。

## 7. 门控、池化、共享头：哪些值得改，哪些已排除

粗门控`gc*hc`以sigmoid约0.5为起点，完整观察会把大部分粗表示压低；零观察又完全不压。这将“看到多少细区域”和“粗表示幅度变化”绑在一起。q/共享头可能补偿，但不是自然的恒等中性点。候选`2*sigmoid(u)`配最后层零初始化可以使起点为1；它与细编码器残差缩放是不同部位，应分别验证。

细门控没有饱和证据；不需要通过加强sigmoid饱和或把注意力人为变尖来解释/修复。best细患者池化接近等权，W157替换等权的输出变化约2.09e-5。

本轮核对池化评分梯度：`dL/ds_i = w_i * <dL/dz, x_i-z>`，自动微分与解析式吻合。相对直接值路径，评分路径对输入区域表示梯度的范数比中位数best约1.49%、last约5.07%。这是局部冻结读出梯度分解，不能解释成评分参数只更新了1.49%，也不证明整个网络无梯度。区域输出相近时，评分信号天然较弱。

[ABMIL原文](https://proceedings.mlr.press/v80/ilse18a.html)提供可学习、对顺序不变的加权聚合；权重是否真实影响预测仍需观测。[CIA-MIL，MIDL2026](https://proceedings.mlr.press/v315/chraki26a.html)及[官方代码说明](https://github.com/ImaneCR/CAR-MIL/blob/main/README.md)进一步用等权/随机反事实衡量和训练注意力的作用。这支持当前“与等权比较”的诊断方法，不意味着本轮应移植其分类CE目标或新增训练损失。

共享融合第一层严格等价`Wc*zc+Wf*zf+Wq*q+b`，拆成3个Linear再相加不会独立获得收益。W157共享头梯度未见平均方向相反，目前没有依据优先删除辅助任务。

## 8. 年度损失的数据利用限制与训练代码检查

真实Train计数：292人、55事件，删失237人。按完整随访年度0/1/2/3/4/5分组的删失人数分别29/86/67/26/8/21。

当前定义中，首年内删失没有完整生存区间，也没有事件项，所以29人约9.93%的图像NLL及梯度均为0。不是读不到病理数据，也不是把他们判成死亡；专指预测网络的图像似然监督，删失模型统计等其他用途另论。292目标重新编码全部一致，16种边界/事件组合与概率形式NLL吻合，29名早删失的零梯度逐一核对。

年度输出协议丢弃区间内部分随访长度。[Kvamme与Borgan原文](https://link.springer.com/article/10.1007/s10985-021-09532-6)区分离散hazard和PC-Hazard；后者可通过区间内暴露比例利用这段随访。未来即使保持五个年度输出点，也可以单独研究连续区间似然，但必须另行登记方法/可比性。本轮不改时间边界、标签或目标，也不把删失时间凑整当成随访完成。

源码核对训练态切换、随机患者顺序、梯度累积尾组实际人数、裁剪、step和zero_grad，未发现该处实现错误。0.4 random+0.4 full+0.1 coarse_aux+0.1 fine_aux中，random自身含25%零细、25%完整；在至少2个可观察父区域时，期望粗/完整/中间部分/纯细监督权重约0.2/0.5/0.2/0.1，并非四种各占25%。这是当前训练设计，尚无依据改权重或把不同目标平均值直接同NLL曲线比较。

## 9. 建议的处理顺序

1. 粗门控的恒等中性点：具体、低成本，保持其余结构和目标不动。
2. 细上下文自注意力残差幅度：本次新定位的重点。可考虑小初值可学习缩放；不要同时换编码器、池化和损失，不能把冻结0.1干预当作已选中的最佳超参。
3. 局部跨注意力入口：记录Q/K投影量级、等权差异及粗query干预敏感性，再检查KV归一化是否提高有效引导。暂不优先堆新的复杂融合头。
4. 时间似然的数据利用另列方法议题，不能夹带到归一化单因素比较。

这是候选排序，不是新的实验队列。若实施，继续固定一个癌种/一个开发划分的短程单因素规则，不自动扩折、seed或模块组合。没有证据表明上述任一改动已解决过拟合。
