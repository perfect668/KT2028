# W136：轻量预测、信息聚合与选区模块调研

检索日期：2026-11-08。范围为2025–2026年预测/信息聚合/动态计算原始论文及作者源码，并核对SuperMimic。本文是适配筛选与实验登记，不是这些方法已在本队列取得增益的报告。冻结UNI、OS、5×/20×和患者身份保持。

## 结论与优先级

先做可归因的128维R3容量对照、同预算随机/学习选区和固定/交替更新，再试一个增加516参数的注意力输出门控。暂不堆叠多个新模块。新分支只用W135第一折训练/内部验证，CRC395/44、LUAD327/36；外层患者不进入训练/选模/新评价。这两组为已观察问题后的开发研究，不能包装为新盲测。既有五折正式队列照常运行。

## 已登记并行开发实验

每癌种依次运行5项，共10个开发run：

1. **R3-128**：761351参数；原0.4随机/0.4全细/0.1粗辅助/0.1细辅助训练、原五模式平均内部验证NLL选模，100轮上限/耐心15。与W135同患者划分，主要用于容量对照；0.2模式作为随机预算参照。
2. **冻结预测器训练选择器**：从R3-128 best初始化，冻结预测器及其coarse状态编码快照；小MLP由coarse token、coarse全局表示、归一化坐标和有效fine数量评分。只读选中的fine；预算为20%有效parent region（向上取整），另记真实fine patch数。训练采用Gumbel top-k的Plackett–Luce采样与精确slate log-probability、REINFORCE奖励random NLL−selected NLL，advantage裁剪±2、entropy系数0.001；固定4轮，内部验证选配套best。
3. **固定选择器、适配预测器**：以第2项所选配套权重为共同起点，冻结选择器和状态编码，预测器更新6轮；训练损失0.5选区＋0.25随机同预算＋0.25粗尺度NLL，lr5e-5。作为交替训练控制。
4. **交替训练**：同一初始化，每轮先固定预测器更新选择器一遍训练患者，再固定选择器更新预测器一遍，6轮；预测器损失和更新次数与第3项一致，policy lr1e-4。每个round评价/保存配套权重，不拼接不同轮次最优。选择状态采用固定coarse编码快照以避免表示漂移与未选择fine泄漏。不能称与第3项同总计算量，策略更新额外计算已披露。
5. **R3-128＋SDPA输出门控**：761867参数，其余训练/选模同第1项，单独测试跨领域模块，不同时加入选区或新损失。

策略从不读取结局作为输入；结局仅训练NLL奖励。首年内删失在现年度NLL下奖励为零，策略更新跳过此类零信息患者，预测器训练/评价仍保留全部患者。固定预算下读取成本为常数，故不额外设置虚假可学习cost/STOP奖励。所用是一次性slate选择，后续序贯获取与STOP另登记。

新进程最多使用GPU总显存18%、CPU线程1；先测试最大训练coarse bag的全输入前向/梯度，再实际更新。发生OOM或程序异常停止新队列并保留现场，不杀旧任务、不自动改变预算/容量重试。两个任务竞争同一GPU/I/O，实际推进和耗时分别记录，不依据瞬时0% GPU判断停工。

已有feature目录仅链接读取，数据不复制，权重/特征留服务器；只同步匿名状态、曲线和比较图。选区坐标图不含患者ID，按固定哈希选定内部验证示例，显示读取比例与真实NLL，不能将高分区域解释为已验证病理因果区域。

## 后续判定

- 128维减轻过拟合但性能不升：继续检查输入组织、标签/随访、指标实现与精细内容贡献，而非仅缩网络。
- 学习选区未超过同预算随机：不宣称选择有效，保留负结果；必要时再尝试冗余约束/渐进压缩。
- 交替训练不如固定选择器：不以“双方共同训练”自动算创新收益；检查策略是否利用训练奖励、评价器漂移与奖励支持。
- 跨领域门控无效：不扩成多模块拼接。所有新方案先在内部开发完成并冻结，再登记后续正式评价；旧外层成绩已被看到的事实保留。
